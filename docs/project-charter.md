## Objetivo

Desenvolver um agente corporativo capaz de responder perguntas com base em documentos internos fictícios, utilizando RAG e apresentando fontes verificáveis.

## Entrega mínima protegida

1. Repositório público.
2. Histórico profissional de commits.
3. Processamento de PDF e CSV.
4. Chunking e embeddings.
5. Banco vetorial.
6. Recuperação semântica.
7. Respostas fundamentadas.
8. Fontes visíveis.
9. Fallback seguro.
10. Interface web.
11. Deploy na OCI.
12. Evidência em nuvem.
13. README completo.

- oito formatos documentais;

- Docker;
